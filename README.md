# 서울 평생교육이용권 지도

서울 평생교육이용권 사용처를 지도에서 찾아보는 정적 웹앱입니다. `index.html` 한 장으로 동작하며 빌드 과정이 없습니다.

## 데이터 출처

- [서울 평생교육이용권 사용처 안내(lllcard.kr)](https://www.lllcard.kr/reg/seoul/guide/useVcOrgan.do)
- 좌표는 주소 기반 카카오 로컬 API 지오코딩으로 보완
- 접수 상황·이용권 사용 가능 여부는 조사 시점 기준이며 방문·신청 전 재확인이 필요합니다.

## 기술 스택

- Leaflet + OpenStreetMap 타일
- 빌드 없는 정적 HTML/CSS/JS, GitHub Pages(main 브랜치) 배포

## 안내 문구

본 사이트는 정보 공유 목적의 비영리 제공입니다. 무단 복제·재배포를 금합니다. 공공데이터를 가공해 제작했으며,
표시되는 기관명·상표 등의 권리는 해당 권리자에게 있습니다. 위치 정보는 근사치일 수 있으니 참고용으로만 이용하세요.
